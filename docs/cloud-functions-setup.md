# إعداد Cloud Functions (نسيت كلمة المرور + حذف الحساب نهائيًا)

خطوتان فقط أنت من يقدر يسويهما — دفع/حساب طرف ثالث لا أقدر أعمله نيابة عنك.
بعدهما أقدر أكمل النشر بنفسي.

## 1) تفعيل خطة Blaze على مشروع Firebase

Cloud Functions لا تعمل إطلاقًا على الخطة المجانية (Spark). لازم الترقية
لخطة Blaze (دفع حسب الاستخدام):

1. افتح: https://console.firebase.google.com/project/tujjar-almawashi/usage/details
2. اختر **Blaze**، وأضف وسيلة دفع.
3. ما في اشتراك شهري ثابت — تُحاسَب فقط على ما يتجاوز الحصة المجانية الشهرية
   لـ Cloud Functions (2 مليون استدعاء، 400,000 GB-ثانية، إلخ)، وبحجم استخدام
   موقعك الحالي يكاد يكون الفاتورة **0 ريال شهريًا**.

## 2) حساب لإرسال الرسائل النصية (SMS)

Firebase نفسه ما يرسل SMS — تحتاج مزوّد خارجي. المقترح لأرقام السعودية:
**Unifonic** (شركة سعودية، دعم عربي، توثيق واضح): https://unifonic.com

1. أنشئ حساب على Unifonic.
2. من لوحة التحكم، احصل على:
   - **App Sid**
   - **Sender ID** (اسم أو رقم المرسل الذي يظهر للمستلم — يحتاج أحيانًا موافقة
     مسبقة من المزوّد حسب نوع الحساب)
3. أرسل لي القيمتين، أو اضبطهما بنفسك مباشرة (بدون ما تشاركني إياهما) عبر:

```bash
firebase functions:secrets:set UNIFONIC_APP_SID
firebase functions:secrets:set UNIFONIC_SENDER_ID
```

(كل أمر يطلب منك لصق القيمة في الطرفية — تُخزَّن مشفّرة في Google Secret
Manager، ولا تظهر أبدًا في الكود أو الـ git).

> إذا كان عندك حساب فعلي بالفعل عند مزوّد ثاني (Twilio مثلًا)، أخبرني وأعدّل
> دالة الإرسال في `functions/src/index.ts` لتتوافق مع API الخاص فيه بدل
> Unifonic.

## 3) النشر

بمجرد ما الخطة مفعّلة والسرّين مضبوطين، شغّل:

```bash
firebase deploy --only functions --project tujjar-almawashi
```

أو أخبرني وأنا أنشرها من هنا مباشرة.

## ملاحظة

كل شيء عدا هذين البندين جاهز ومبني ومختبر بالفعل — الواجهات (نسيت كلمة
المرور، رمز التحقق، إعادة التعيين)، منطق Firestore، وقواعد الأمان كلها
منشورة على الموقع الحي الآن. الشيء الوحيد الناقص هو تفعيل الإرسال الفعلي
للرسائل، والحذف الفعلي لحساب Auth — وكلاهما ينتظر الخطوتين أعلاه فقط.
