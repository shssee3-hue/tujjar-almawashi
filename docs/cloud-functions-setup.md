# إعداد Cloud Functions (نسيت كلمة المرور + حذف الحساب نهائيًا)

## 1) خطة Blaze

**آخر فحص مباشر لي على المشروع لسّه يُظهرها غير مفعّلة** (تأكدت عبر
`firebase deploy --only functions` مباشرة وعبر Cloud Billing API، فشلا
بنفس الخطأ). تأكد أن الترقية اكتملت فعليًا (أحيانًا تحتاج تأكيد وسيلة الدفع
لتكتمل) من هنا:

https://console.firebase.google.com/project/tujjar-almawashi/usage/details

## 2) حساب Authentica

اخترت **Authentica** (https://authentica.sa) — منصة سعودية متخصصة تحديدًا
في التحقق عبر OTP (وليست مزوّد SMS عام)، تناسب هذا الاستخدام بالضبط.

1. أنشئ حسابًا على authentica.sa.
2. من لوحة التحكم، احصل على **مفتاح API**.
3. اضبطه كسرّ في Firebase:

```bash
firebase functions:secrets:set AUTHENTICA_API_KEY
```

(الأمر يطلب منك لصق القيمة في الطرفية — تُخزَّن مشفّرة في Google Secret
Manager، ولا تظهر أبدًا في الكود أو الـ git). أو أرسل لي المفتاح مباشرة
وأضبطه أنا.

> **تنبيه مهم:** لم يكن عندي حساب Authentica فعلي وقت كتابة كود الربط
> (`functions/src/authentica.ts`)، فبنيته على أفضل تخمين لشكل الـ API بناءً
> على نموذج "OTP-as-a-service" المعلن عنهم. بمجرد ما ينشأ حسابك، أحتاج
> أراجعه مقابل توثيق الـ API الفعلي في لوحتك (عادة تحت قسم Developers/API)
> للتأكد أن مسارات الطلبات وأسماء الحقول مطابقة تمامًا قبل ما أعتمد عليه
> فعليًا — أرسل لي رابط التوثيق أو لقطة شاشة منه إن قدرت.

## 3) النشر

بمجرد ما الخطة مفعّلة فعليًا والسرّ مضبوط:

```bash
firebase deploy --only functions --project tujjar-almawashi
```

أو أخبرني وأنا أنشرها من هنا مباشرة.

## ملاحظة

كل شيء عدا هذين البندين جاهز ومبني ومختبر بالفعل — الواجهات (نسيت كلمة
المرور، رمز التحقق، إعادة التعيين)، منطق Firestore، وقواعد الأمان كلها
منشورة على الموقع الحي الآن. الشيء الوحيد الناقص هو تفعيل الإرسال الفعلي
للرسائل عبر Authentica، والحذف الفعلي لحساب Auth — وكلاهما ينتظر الخطوتين
أعلاه فقط.
