# خارطة الطريق (Roadmap)

نقاط تحسين مستقبلية، مأخوذة من التقرير النهائي ومتابَعة كـ Issues على
GitHub (راجع تبويب Issues بالمستودع لحالتها الحالية):

1. **تحسين صفحة الإعلانات** — ✅ جزئيًا: `listAds()` صار يفلتر ويُرقّم من جهة
   الخادم (قسم/منطقة + مؤشّر). يبقى: فلترة `breed`/`subCategory` من جهة الخادم
   أيضًا، وعرض عدد إجمالي دقيق.
2. **نظام دفع فعلي للإعلانات المميزة** — ربط بوابة دفع (مدى/Apple Pay عبر Moyasar أو Tap) بدل التفعيل اليدوي الحالي من لوحة التحكم.
3. **تحسين لوحة التحكم** — تقارير/إحصائيات أعمق للمالك.
4. **دعم رفع صور متعددة بجودة أعلى** — ✅ تم الانتقال إلى Firebase Storage
   (خطة Blaze). سكربت الترحيل: `frontend/scripts/migrate-images-to-storage.mjs`.
   يبقى كتحسين: رفع حدّ الحجم/الجودة الآن بعد زوال قيد Base64.
5. **تحسين SEO** — عناوين/أوصاف Meta ديناميكية لكل إعلان، Sitemap.
6. **التحقق من رقم الجوال (OTP)** — ✅ عبر Firebase Phone Authentication.
7. **نظام تقييم فعلي للبائعين** — ✅ دالة `recomputeSellerRating` تجمّع تقييمات
   إعلانات البائع وتكتب `users.rating` / `ad.sellerRating`، وتُعرض في صفحة
   الإعلان والملف الشخصي.

## مقترحات إضافية

- ربط اسم نطاق مخصص (مثل tujjar-almawashi.sa) بدل الرابط الفرعي الحالي.
- ✅ اختبارات آلية لقواعد Firestore + CI (GitHub Actions) — راجع
  [`testing.md`](./testing.md). يبقى: اختبارات e2e للواجهة.
- قائمة مدن معتمدة لكل منطقة بدل الحقل النصي الحر الحالي.
